## 2026-09-26 — 전 메뉴 점검, 워커 차선·생존 신호, 백업, 성능·접근성

검증 방법과 결과는 [품질 검증](quality.md).

**버그 수정**
- 범위를 넘는 숫자(`page=99999999999`, `types=99999`)가 DB 에서 `bigint/smallint out of range` → **500** 이던 것 4곳 → 입력 범위 검사 +
  DB `DataError` 를 400 `VALIDATION_ERROR` 로 (API 퍼징 534요청에서 발견, 이제 5xx 0건).
- 지역 순위: 시도 목록이 늦게 오면 **같은 순위 요청을 두 번** 보내던 것, 데이터·운영: 품질 요약을 머리글과 본문이 두 번 요청하던 것.
- 오류 로그: DB 오류 한 건이 SQL 원문 전체(수십 줄)를 찍어 로그 창을 덮던 것 → 한 줄 요약(SQL·바인드 값 제외, 자세한 내용은 traceId 로 서버 로그).
- 방문 여건: 미세먼지 예보가 아직 없는 날짜의 출처 표시가 `에어코리아 발표 —` 로만 나오던 것 → "아직 이 날짜까지 발표되지 않음".

**아키텍처** ([ADR-017](adr/ADR-017-worker-lanes-ops.md))
- 워커 **차선(short·long)** — 25분 걸리는 도로 거리 수집이 예보 갱신을 막지 않음. `atlas worker --lane` 으로 나눠 띄우기 가능.
- 워커 **생존 신호**(`ops.worker`, V16) → `/health` 의 `workers`, 데이터·운영 배지, compose healthcheck(`atlas worker-check`).
- DB 가 연결을 끊으면(장애 복구·재시작) 차선이 1·2·4…30초 간격으로 다시 연결 — 전에는 워커 프로세스가 끝나고 컨테이너가 재시작됐음(실제로 겪음).
- `GET /health/live`(생존)와 `GET /health`(준비) 분리.
- `make backup` / `make restore` — 경량 백업 113MB·14초, 임시 DB 복원으로 건수·권한 일치 확인.
- 웹: 조회용 요청 캐시(`cachedApi` — 같은 경로 동시 요청 합치기, 실패는 캐시 안 함) → 메뉴를 옮길 때마다 받던 머리글 요청 3개와
  지도 GeoJSON(212KB) 재요청 제거(지도 재방문 요청 0개).

**성능·UX**
- 지도: 폴리곤 생성(좌표 수만 개)을 약 12ms 조각으로 나눠 브라우저에 양보 → 느린 기기에서 가장 긴 작업 532 → 316ms.

## 2026-09-25 — 생활 거점·영업일, 작업 큐 아키텍처, 보안·성능 강화

**기능**
- **생활 거점** (`/hubs`): 국립중앙의료원 약국·병의원 FullData(약국 25,442 · 의원급 42,514)로 집계구마다 은행·약국·의원·공휴일 진료처 거리 →
  우체국이 마지막 생활 거점인 인구·의료 공백·공휴일 의료 공백 지표 6종, **우체국별 대체 불가능성**(`facility_hub`) 순위.
  What-if 에 '생활 거점 상실 인구', 배치 제안에 경고, 시설 카드에 주변 약국·의원·은행, 지도에 약국·의원 레이어(공휴일 진료만).
- **영업일 달력**: 한국천문연구원 특일 정보 + 주말 → 창구 휴무 판정. 방문 여건 연휴 모드(365코너 없는 읍면동·공휴일 의료 공백),
  머리글 '오늘 휴무' 알림, 시설 카드 '지금 영업 중/휴무', `GET /calendar`.
- UI: 모든 화면 조건을 주소에 저장(공유·새로고침), 주제별 지표 묶음, 불러오는 중 자리 표시, 0 이 많은 지표의 범례 개선,
  키보드 포커스 링·본문 건너뛰기·`Esc`, 데이터·운영 화면에 작업 큐·스케줄, 지표 정의에 규칙 카드.
