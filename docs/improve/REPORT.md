## 3. 의도적으로 바꾼 동작

**API 응답**
- 시설 상세 `status.state` 에 `lunch` 가 생겼습니다('점심시간 · 13:00 다시 열림'). 화면은 open 이 아닌 상태를 회색으로 그립니다.
- 400 `VALIDATION_ERROR` 로 바뀐 입력
  - 유니코드 숫자 지역 코드: 예전에는 404·200
  - NaN·무한대·뒤집힌·경위도 밖 `bbox`: 예전에는 200
  - 해석할 수 없는 본문: 예전에는 `HTTP_ERROR`
  - 잘못된 계산 설정의 관리 작업 요청: 예전에는 202 를 받고 워커에서 실패
- 지도 `simplify` 는 9단계로 반올림됩니다. 예전에는 10m 단위였고, 화면은 이 값을 쓰지 않습니다. 기본값을 적은 요청은 생략한 요청과 같은 캐시를 씁니다.
- `/csp-report` 는 깨진 입력에도 204 입니다. 처리하지 못한 예외 기록은 시간당 300건까지만 남고, 넘으면 서버 로그에만 남습니다.
- 웹 프록시(:3100): GET·HEAD 에 본문이 붙으면 400, PUT·DELETE 등은 405 와 `Allow` 헤더.

**계산·수집 결과**
- 지금 데이터로 바뀌는 결과
  - 같은 좌표 은행 지점의 이용 주민이 id 가 가장 작은 지점으로 모입니다(b1 이 바뀌는 집계구 310곳, 거리는 같음).
  - 경계 밖 16m 의 은행 지점 1곳에 소속 지역이 생깁니다.
- 결과는 그대로이고 상태 판정만 엄격해진 것
  - 우체국: 가운데 쪽이 비거나 크게 모자라는 지역코드는 미완료가 됩니다(지금 원문에서는 해당 0건).

  - SGIS: 직전 연도 대체는 '자료 없음'(0건·-100)일 때만 합니다.
- 판정 규칙이 바뀌면 판정이 바뀐 시설의 이력을 닫고 새로 엽니다(지금은 해당 0건).
- 약국 삭제 보류·은행 전수 미완료의 PARTIAL 실행에 사유(건수만)가 생겨 오류 로그에 보입니다. 우체국 대량 폐국 멈춤은 품질 ERROR `MASS_CHANGE_HELD` 로 남습니다.
- 계산·수집을 Ctrl-C 로 멈추면 실행 기록이 FAILED 로 닫힙니다.

**화면**
- 지도
  - 주소에 조건이 있으면 기본 조건으로 먼저 받지 않습니다. 그래서 파라미터가 없는 `/` 도 한 렌더 뒤에 요청합니다.
  - 지역 카드는 지도 응답(계산 실행 id)이 온 뒤 요청하고, 그동안 닫기 단추가 있습니다.
  - 바깥에서 온 주소(머리글 '지도'·뒤로 가기)는 화면 상태 전부를 주소대로 바꿉니다. 열린 시설 카드도 닫힙니다.
  - 시도 전체 읍면동에서 고른 지역은 새로고침해도 시도 범위가 유지됩니다.
- 시각은 브라우저 시간대와 관계없이 KST 로 보입니다. 날짜만 있는 값은 KST 자정으로 해석합니다.
- 카카오 지도 본체가 막히면 오류 문구를 보이고, 15초 뒤 첫 렌더에서 다시 시도합니다.

- 품질 화면의 표 3개는 불러오는 중이면 자리 표시, 실패하면 오류 상자를 보입니다.

## 4. 그대로 둔 것과 이유

리뷰어가 확인하고 '고칠 이유 없음'으로 본 것들입니다. 근거는 리뷰 원자료에 있습니다.

**보안·API**
- 관리 토큰을 상수 시간으로 비교하고, 토큰이 비면 503 으로 꺼짐.
- 최소 권한 역할(atlas_api)이 API 가 실제로 쓰는 표와 정확히 일치함.
- 본문 64KB 상한은 Content-Length 가 없거나 거짓이어도 동작함.
- XFF 를 오른쪽부터 해석함.
- ETag·304 와 gzip 의 순서.
- 수집기마다 원문에서 키를 가림.
- `/metrics`·`/docs` 는 웹 프록시로 노출되지 않음.
- What-if 는 커밋 뒤에 캐시하고, 동시 요청은 ON CONFLICT 로 받음.

**수집·작업 큐**
- 재개 범위(reopen_run), 병합 상한과 그 상한이 세는 대상.
- 약국 완전성 확인(D2·D3 1차 수정).
- 날씨·대기 upsert 의 '더 새 발표만'.
- 작업 큐의 claim(SKIP LOCKED + V23), heartbeat·finish 의 소유 확인.
- 격리 실행의 spawn·시간 제한.
- 스케줄의 자정 넘는 창.
- 계산 SQL 이 모두 계산 실행 단위로 필터됨.

**계산**
- 0 나누기와 NULL 처리, 거리 단위.
- 우체국 최근접 동률 처리(02·06 — 같은 좌표 묶음 0건).
- '먼 거리' 경계의 일관성.
- What-if 부분 재계산이 전체 재계산과 같음.

**화면**
- 말풍선 이스케이프, `useApi` 의 취소·늦은 응답 무시.
- 지도 레이어가 바뀐 점만 갱신함.
- poller 의 중복 타이머 방지.
- 사용자 동작의 중복 제출 방지.

**리뷰가 반박한 지적** (근거는 PLAN 3장)
- CI 와 로컬 PostGIS 이미지 차이(ADR-007 의 의도된 결정).

- What-if 캐시 테스트 보강.
- 우체국 중복 항목 계산.

**개선 제안 — 바꿀 기준에 해당하지 않아 남김** (리뷰 원자료 약 60건 중 주요한 것)
