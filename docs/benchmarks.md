# 벤치마크 기록

`make bench` — 측정 동안만 속도 제한을 끄고(api 재기동), 같은 도커 네트워크의 collector 컨테이너에서 경로마다 동시 16개로
200회(What-if 50회) 요청합니다. uvicorn 워커 2, PostgreSQL 16 + PostGIS 3.6, Redis 7, Apple Silicon 로컬, 전국 실데이터.
끝에 `pg_stat_statements` 누적 시간 상위 SQL 을 함께 출력합니다.
