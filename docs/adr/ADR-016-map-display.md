# ADR-016 지도 표시 방식 — 늘 보이는 정보, 확실한 첫 그리기

- 상태: 채택 (2026-09-25)

## 맥락
- 사용자 환경(고해상도·일부 브라우저)에서 단계구분도 폴리곤이 **마우스를 올려야** 색이 보였다. 폴리곤을 지도에 먼저 붙이고
  `setBounds` 로 화면을 옮기면, 이동 뒤 벡터 층을 다시 그리지 않는 경우가 있었다(마우스 오버 = 그 영역 다시 그리기).
- 정보도 마우스 오버 말풍선에만 있어 터치 기기에서는 볼 수 없고, 한눈에 핵심 지역이 보이지 않았다.
- 방문 여건 지도(높이 560px)는 카카오 확대 단계가 2배씩이라 전국이 한 단계 안에 안 들어가 한 단계 더 멀리(작게) 보였다.

## 결정
1. **맞추고 → 붙이고 → 칠하기**: 폴리곤을 지도에 붙이지 않은 채 만든 뒤 `setBounds`, 이동이 끝난 `idle`(없으면 400ms)에서 한꺼번에
   `setMap` + 칠하기 + 다음 프레임에 한 번 더 칠하기. 컨테이너 크기가 바뀌면(`ResizeObserver`) `relayout` 후 다시 칠하고,
   탭이 다시 보일 때(`visibilitychange`)도 다시 칠한다.
2. **늘 보이는 라벨**: 지도마다 핵심 지역을 대표점(`ST_PointOnSurface`, GeoJSON 속성 lat·lon)에 알약 라벨로 표시 —
   지도: 선택 지표의 취약 상위 8곳(순위·값, 끄기 가능) · 방문 여건: 먼저 살펴볼 지역(원인) · 배치 제안: 우체국이 가장 먼 5곳 ·
   What-if: 거리가 가장 많이 늘어나는 5곳. 화면 좌표로 **겹침을 판정해 우선순위가 낮은 라벨은 숨기고**, 확대하면 다시 보인다.
3. **누르면 고정**: 지역을 누르면(터치 포함) 말풍선이 고정되고, 빈 곳이나 같은 지역을 다시 누르면 닫힌다
   (카카오는 도형 클릭 뒤 지도 클릭도 보내므로 300ms 안의 지도 클릭은 무시). 지도 화면은 누르면 오른쪽 상세 카드.
4. 방문 여건 지도 높이를 700px 로 — 전국(위도 5.5°)이 한 단계 가까운 수준(13)에 들어감.

## 대안
- 폴리곤을 캔버스·SVG 오버레이로 직접 그리기: 확대·이동 동기화를 직접 해야 해 복잡도 대비 이득이 작음.
- MapLibre GL 로 교체: 벡터·라벨·호버 상태가 강력하지만 한국 지도 타일(카카오)을 쓸 수 없어 배경 지도 품질·약관 부담.
