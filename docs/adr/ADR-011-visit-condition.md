# ADR-011 방문 여건 — 기상청 단기예보 + 에어코리아 미세먼지 예보

- 상태: 채택 (2026-09-24)

## 맥락
이 서비스의 지표(거리·인구·금융 공백)는 모두 **정적**이다. 운영자가 매일 들여다볼 이유가 약하고,
"멀리 사는 고령자"가 실제로 창구에 가기 어려운 날(폭우·폭설·폭염·한파·강풍·고농도 미세먼지)을 반영하지 못한다.
보유 키 후보: V-World, 한국부동산원, Open DART, 한국도로공사, 에어코리아, 한국철도공사, 기상청 단기예보.

## 결정
**기상청 단기예보 + 에어코리아 대기질 예보** 두 개를 쓴다.

- 둘 다 공공데이터포털 일반 인증키 하나(`DATA_GO_KR_KEY`)로 쓸 수 있고, 전국을 빠짐없이 덮으며 하루 여러 번 갱신된다.
- 기존 핵심 지표 `AGED65_FAR_PPLTN`(우체국 2km 밖 65세 이상)과 곱하면 "오늘 방문이 특히 어려운 사람 수"라는
  바로 행동으로 이어지는 값(찾아가는 우체국·전화 안내·배달 금융 우선 지역)이 된다.
- 다른 후보를 뺀 이유: V-World 는 경계·주소를 SGIS·카카오로 이미 갖췄고, 부동산원·DART 는 접근성과 관련이 약하며,
  도로공사(고속도로)·철도(열차 운행)는 농산어촌 고령자의 창구 방문 경로와 거리가 멀다.

## 방식
- **격자**: 시군구 대표점 → 기상청 LCC 5km 격자(`mart.area_grid`). 중복을 빼면 약 240 격자 = 수집 1회 약 240호출(일 한도 1만).
  읍면동(3,500곳)까지 내리면 호출이 10배라 시군구 단위로 판정하고, 지역 카드에서 읍면동은 상위 시군구 판정을 보여 준다.
- **시간 예보 보존**: `mart.weather_hourly` 는 (격자, 예보시각) 키로 **더 최근 발표만 덮어쓴다**. 오후에 받아도 오전 시각은
  앞선 발표가 남아 하루 운영 시간(09~18시) 전체를 판정한다. 14일 지난 시간은 수집 때 정리.
- **대기**: `getMinuDustFrcstDspth`(PM10·PM25) 는 19개 권역 등급. 시도 코드 → 권역, 경기(북부/남부)·강원(영동/영서)은
  시군 이름으로 나눈다. 예보일마다 가장 최근 발표만 저장.
- **판정(VISIT-1)**: 조회 때 파이썬 순수 함수(`atlas/domain/visit.py`)로 계산한다. 규칙을 바꿔도 재수집·재계산이 필요 없고,
  단위 테스트로 경계값을 고정한다. 기상특보·대기 등급 기준을 참고했지만 공식 특보가 아님을 화면에 표시한다.
- **키 처리**: 기존 Fetcher 로 raw 저장(serviceKey 마스킹 + 키 원문 치환). 게이트웨이의 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`
  (403 JSON)·XML 오류 봉투·`resultCode 22`(한도) 는 즉시 중단(DataGoStop).

## 결과
- `make weather`(약 2분), 화면 `/today`, 지역 카드 「방문 여건」, 한눈에 배너, API `GET /visit/conditions[/{admCd}]`.
- 한계: 시군구 안 날씨 차이(산간·해안)는 대표점 격자 하나로 대신한다. 미세먼지는 권역 예보라 시군구 차이를 반영하지 못한다.
