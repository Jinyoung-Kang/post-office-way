# ADR-008 우편 지역코드 seed 자동 탐색

- 상태: 채택 (명세서 코드표 확보 시 대체 가능)
- 맥락: FR-101 은 명세서 지역코드표를 seed 로 쓰라고 하지만 원본 .docx 가 작업 환경에 없다.
- 결정: 명세 예시(100 = 서울 중구 일대, 367 = 괴산·증평)로 보아 옛 우편번호 앞 3자리 체계로 보고, `make discover` 가
  100~799 를 pageCount=1 로 한 번씩 호출해 totalCount > 0 인 코드만 `seed/area_codes.csv` 에 쓴다.
  기존 seed 에만 있던 코드(명세서에서 옮긴 `c` 코드 등)는 보존한다. 처음 10개가 모두 실패하면 키·주소 문제로 보고 중단.
