# ADR-018 은행 지점 폐쇄 영향평가 — 전수 수집·이용 주민·대체 창구(은행대리업 우체국)

- 상태: 채택 (2026-10-08)

## 맥락
- 2026년 은행 점포폐쇄 공동절차가 개정됐다(평가 항목 4 → 8개, 인근 점포 10km 초과·고령층·실제 이동거리 반영, 사전영향평가 내용 공개).
  같은 해 7~10월 우정사업본부가 시중·지방은행과 은행대리업·공동이용 협약을 맺어 전국 2,400여 우체국에서 입출금을 한다.
  → 우체국은 **은행 점포가 닫힐 때의 공식 대체 수단**이 됐지만, 은행이 하는 사전영향평가는 지점별·은행별이고 일부만 공개된다.
- 이 서비스는 은행 지점·우체국·집계구 인구를 이미 갖고 있어, **모든 지점을 같은 기준으로** 평가할 수 있다
  (해외 사례: 영국 LINK 의 Cash Access Assessment — 지점이 닫히면 반경 안 대체 서비스를 평가해 공개).
- 그런데 은행 지점 자료는 '지역 대표점마다 가까운 3곳'만 모아(ADR-010) 도시 지점이 많이 빠져 있었다(은행 약 4,300곳).

## 결정
1. **전수 수집(사분할 격자)** — 카카오 범주 검색은 한 요청에 최대 45곳이라, 사각형의 `total_count` 가 45 를 넘으면 네 칸으로 나눠
   다시 묻는다(최소 약 200m, 그보다 작으면 잘림으로 기록). 4,800회 · 8.7분 · 실패·잘림 0 → 대면 지점 8,642곳(은행 5,425).
   - 마지막 **전수 수집(DONE)에서 보이지 않은 지점은 폐점 가능성으로 계산에서 뺌** — `mart.bank_branch_current` 뷰 하나를
     계산과 API 가 함께 씀(72곳 제외). 실패한 칸이 있으면 PARTIAL 이라 기준 목록이 되지 못함.
2. **은행 브랜드·은행대리업 표(`mart.bank_brand`)** — 카테고리 마지막 칸이 브랜드. 은행대리업 대상 여부는 코드가 아니라 표의
   `post_agent` 열이라 협약 은행이 바뀌면 행만 고친다. 보도된 '국내 14개 시중·지방은행 모두'의 은행별 명단은 공개 자료에서
   확인하지 못해 시중·지방·특수은행 전체를 대상으로 **가정**하고 화면에 표시한다. 새마을금고·저축은행은 공동절차 대상이 아니라
   평가하지 않고 대체 창구에도 넣지 않는다(보수적).
3. **평가 단위** — 집계구(평균 500명)마다 가장 가까운 은행 지점 = 그 지점의 **이용 주민**. 닫히면 대체 창구 = 다음으로 가까운
   다른 은행 지점 또는 금융 우체국 중 가까운 곳. 결과는 calc_run 마다 `mart.bank_impact`(지점) · `mart.oa_bank`(집계구)로 보존.
4. **잃는 주민의 정의** — 처음에는 '닫히면 2km 안 대체 창구가 없는 이용 주민'으로 셌더니 전국 516만 명이 나왔다. 이미 2km 밖에
   살던 주민까지 세서다. → **지금은 2km 안에 그 지점이 있는데 닫히면 2km 안 대체 창구가 없는 주민**으로 바로잡음(77만 명).
   이미 먼 주민의 부담은 인구 가중 거리 증가(지금 → 닫힌 뒤)로 보여 준다. 도보는 같은 정의로 30분(1,440m).
5. **등급 BANK-IMPACT-1** — SQL 함수 하나(`mart.bank_impact_reasons` · `mart.bank_impact_grade`)를 지표 계산과 도보 계산이 함께 쓴다.
   높음: 잃는 주민 1,000명+, 또는 잃는 주민이 있으면서 같은 은행 다음 지점 10km 밖·고령 20%+ / 보통: 요인 하나 / 낮음: 없음.

## 결과
- 전국 은행 지점 5,425곳: 높음 254 · 보통 2,387 · 낮음 2,784. 지점마다 따로 닫힌다고 할 때 새로 2km 안 대체 창구를 잃는 주민
  합 77만 명, 걸어서 30분 기준 249만 명. 계산 단계 7.5초, 목록 API 26~43ms.
- 화면 `/banks`(순위·등급·지도·대체 창구·거리대별 이용 주민), 지도의 은행 지점 점을 누르면 이동, 지역 보고서·한눈에 요약.

## 한계
- 카카오 장소 자료는 공식 점포 목록이 아니다(출장소·금융센터 포함, 폐점 반영 시차). 지점의 실제 이용량·대면 의존도는 모른다.
- 지점마다 하나씩 닫힌다고 가정한다(여러 지점이 동시에 닫히는 조합은 What-if 처럼 다루지 않음).
- 고령 인구는 읍면동 고령 비율을 집계구 인구에 곱한 추정이다.
