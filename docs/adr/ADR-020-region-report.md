# ADR-020 지역 한 장 보고서 — 서버에서 묶기 · 계산 버전 캐시 · SVG 작은 지도 · 인쇄

- 상태: 채택 (2026-10-08)

## 맥락
- 국토조사는 전국 보고서, 은행 사전영향평가는 지점별이라 **지자체·지방의회가 들고 갈 시군구 단위 문서**가 없다.
- 한 시군구의 접근성·도보·지켜야 할 우체국·은행 지점 영향·읍면동·방문 여건을 화면에서 따로 모으면 API 를 6~7번 부른다.

## 결정
1. **`GET /areas/{admCd}/report` 한 번** — 서버에서 묶어 한 번에 준다. 시군구(5자리)만 받는다(읍면동은 상위 시군구로 연결).
2. **캐시 키 = (calc_run, 도보 계산 완료 시각, 시군구)** — 계산 결과로 정해지는 부분만 Redis 에 24시간. 날마다 바뀌는 방문 여건은
   캐시하지 않고 매번 붙인다. 도보 계산이 나중에 끝나도 키가 바뀌어 낡은 보고서를 주지 않는다. 캐시 적중 16ms.
3. **전국 비교 기준 = 시군구 중앙값** — 순위·백분위와 함께 '나쁜 쪽에서 N번째'로 쉬운 말로.
4. **작은 지도는 SVG** — 카카오 SDK 없이 읍면동 경계(단순화본)를 등장방형으로 펼쳐 그린다. 인쇄·PDF 에 그대로 나오고 외부 타일 요청이 없다.
   색은 한 색조 밝기 5칸 + 범례, 단계 경계는 지표별 고정값(지역끼리 비교되게).
5. **인쇄** — `@media print` 로 머리글·바닥글·버튼을 빼고 A4 여백, 카드가 쪽 사이에서 잘리지 않게. '인쇄 · PDF 저장' 버튼은 브라우저 인쇄.

## 결과
- 화면 `/report`(시도별 시군구 목록) · `/report/{admCd}`. 지도 지역 카드·은행 지점 상세에서 이동.
- 대안: 서버에서 PDF 생성(헤드리스 브라우저) — 이미지가 커지고 운영할 구성 요소가 늘어 채택하지 않음. 브라우저 인쇄로 충분.
