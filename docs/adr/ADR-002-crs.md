# ADR-002 저장은 EPSG:4326, 거리는 EPSG:5179

- 상태: 채택
- 결정: 지오메트리를 4326(지도 표시)과 5179(UTM-K, 미터) 두 컬럼으로 저장한다. 거리·반경·KNN 은 5179 컬럼만 쓴다
  (위경도 도(degree) 거리 금지, NFR-04).
- SGIS 경계 좌표계: 문서에서 확인하지 못해, 적재 시 첫 좌표의 크기로 판정한다(경위도 범위면 4326, 아니면 5179).
  판정 결과는 `admin_area.src_crs` 에 남는다. `make smoke` 출력의 "좌표계 판정"으로 확인.
