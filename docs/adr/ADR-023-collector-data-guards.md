# ADR-023 수집이 기존 자료를 지우지 않게 — 완전성 확인·대량 변경 상한·범위를 좁힌 삭제

- 상태: 채택 (2026-10-09, 리뷰 계획 D1~D7)

## 맥락
외부 API 는 빈 응답·일부 실패·건수 불일치를 정상 응답처럼 돌려줄 때가 있다. 리뷰에서 다섯 수집기가 '이번에 받은 것 = 전부'로 보고
기존 자료를 지우거나 닫는 경로를 찾았다(각각 실패하는 테스트로 먼저 재현).

| 수집 | 문제 |
|---|---|
| 우체국 시설 | 재개(resume)가 오래되었거나 다른 종류의 실행을 다시 열 수 있었고, 스냅숏 행이 없는 '성공 지역코드'까지 병합해 현재 시설이 대량으로 '문 닫음'이 됨 |
| 약국·병의원 | 응답이 비거나 일부만 와도 받지 못한 기관을 모두 삭제 |
| 은행 전수 수집 | 실패한 쪽(page)이 있어도 DONE — 빠진 지점이 '폐점 가능성'으로 계산에서 빠짐 |
| KOSIS 고령인구 | 일부 시도 호출이 실패해도 그 해 전체를 지우고 다시 넣음 → 실패한 시도의 값이 사라짐 |
| 공휴일 | 응답이 빈 해도 그 해 휴일을 지운 뒤 아무것도 넣지 않음 |

## 결정
1. **완전성을 확인하고 아니면 PARTIAL** — 받은 건수가 응답의 전체 건수보다 적거나, 실패한 칸·쪽·잘린 칸이 있으면 '전수'가 아님.
   PARTIAL 은 기존 자료를 지우지 않고 다음 수집에서 다시 판단한다.
2. **대량 변경 상한** — 한 번에 닫거나 지우는 양이 평소보다 크면 멈추고 품질 ERROR 로 남긴다.
   우체국: 현재 시설의 5% 또는 20곳 중 큰 값 초과(`collector/post/pipeline.py` `MergeGuardError`),
   약국·병의원: 기존의 10% 또는 50곳 중 큰 값 초과면 삭제 보류(`removeHeld`).
3. **삭제 범위를 실제로 받은 것으로 좁힘** — KOSIS 는 성공한 시도만 지우고 다시 넣음, 공휴일은 행이 있는 해만,
   우체국 병합은 스냅숏에 행이 있는 지역코드만.
4. **재개는 같은 종류의 가장 최근 PARTIAL·FAILED 실행만**(`ops/runs.reopen_run`).
5. 복원(`make restore`)도 같은 원칙 — 검증한 덤프를 임시 DB 에 먼저 풀고, 성공하면 이름을 바꿔 교체(ADR-017).

## 결과
- 각 경로를 재현한 테스트(`tests/sql/test_collect_guards.py` 등)가 실패 → 수정 후 통과. 상한값은 운영에서 본 변동 폭(수집당 신규·폐국 수십 곳)보다
  넉넉하게 잡았고, 넘으면 사람이 오류 로그·품질 화면에서 보고 판단한다.
- 대가: 실제로 대량 폐국·대량 삭제가 일어난 날은 자동 반영되지 않는다(의도). 상한은 상수라 바꾸려면 코드를 고친다.
  우체국 수집에서 '성공했지만 0건'인 지역코드는 병합하지 않으므로, 그 지역의 마지막 우체국이 실제로 문을 닫아도 반영되지 않고
  실행 통계(`emptyDoneCodes`)와 로그에만 남는다 — 품질 화면에 드러내는 것은 남은 과제.

## 2차 리뷰 보완 (2026-10-15)
처음 보는 리뷰어가 같은 원칙의 빈틈을 찾았다. 모두 실패하는 테스트로 재현한 뒤 고쳤다.
- **우체국 — 쪽 단위 완전성**: 오류 없는 응답이면 성공으로 봐서, 가운데 쪽이 비거나 잘려도 그 코드가 '성공'이 되어 받지 못한 시설이 닫혔다.
  상한(5%) 아래면 그대로 반영됐다. → 쪽 안에 항목 0개인 쪽이 있거나, 받은 수가 totalCount 보다 max(2곳, 2%) 넘게 모자라면 그 코드는 미완료다.
  미완료 코드는 닫는 근거에서 빼고 재개 대상으로 둔다. 지금 상류가 늘 주는 1~2곳 모자람은 허용치 안이다.
- **KOSIS — '조회결과 없음(30)'**: 모든 시도가 30 이면 받은 값 없이 그 해 전체를 지우고 DONE 이었다. → 30 은 SGIS 경계에 이름이 없는 시도만
  건너뛰고, 있는 시도의 30·빈 목록은 실패로 본다. 받은 값이 없으면 지우지 않고 FAILED 다.
- **SGIS 경계 — 연도 대체**: 일시 오류(HTTP 5xx·시간 초과)에서도 직전 연도로 대체하고 그 연도를 전국에 고정했다. → 대체는 SGIS 가 '자료 없음'으로
  답했을 때만 한다. 그 해에 쓰지 않은 코드를 정리하는 일은 삭제 범위 결정이 필요해 결정 대기(docs/improve/PLAN.md Q2)로 남겼다.
- **주소 검색 캐시**: 일시 오류가 'ERROR' 로 영구 캐시되던 것 → ERROR 는 다시 조회한다.
- **'품질 ERROR 로 남긴다'를 실제로**: 품질 규칙 `MASS_CHANGE_HELD`(ERROR)를 추가했다. 약국 삭제 보류와 우체국 대량 폐국 멈춤(병합을 되돌린 뒤
  따로 기록)에 남긴다. 약국·은행 전수의 PARTIAL 에는 건수만 담은 사유를 실행 기록 error 로 남겨 오류 로그에 보이게 했다.
- **중단에도 기록 닫기**: Ctrl-C 로 멈춘 실행이 RUNNING 으로 남아 수 시간 동안 같은 종류를 막던 것 →
  [ADR-025](ADR-025-run-records-close-on-interrupt.md).
