# ADR-010 고도화 — 집계구·도로 거리·주소 검증·금융 공백·배치 제안

- 상태: 채택 (2026-09-24)
- ① **집계구**: SGIS 에 격자 인구 OpenAPI 가 없어(404) 통계 최소 단위인 집계구(평균 약 500명)를 쓴다. 인구는 시군구마다
  `population.json low_search=2`(252회), 경계는 `boundary/statsarea.geojson` 이 읍면동 단위만 받아 약 3,600회(이어받기).
  계산마다 집계구 1순위를 `mart.oa_nearest` 에 저장해 What-if 가 집계구 단위로 '새로 2km 밖' 인구를 센다.
- ② **도로 거리**: 카카오모빌리티 다중 목적지 API 는 반경 10km 제한이 있어 농산어촌에 못 쓴다 → 단건 길찾기로
  (지역 대표점 → 직선 상위 2곳) 경로를 `mart.area_road` 에 캐시. 1회 호출 예산(ROAD_MAX_CALLS)으로 쿼터를 보호하고 이어서 채운다.
  OSRM 로컬 서버(대용량 OSM 다운로드·전처리)는 유지 부담이 커 보류.
- ③ **주소 검증**: 카카오 주소 검색으로 좌표 없는 시설을 채우고(coord_source='GEOCODE'), 현재 시설 좌표와 주소 좌표가
  1km 넘게 다르면 COORD_ADDR_MISMATCH. 주소 결과는 `mart.geocode_cache`, 검사 결과는 row_hash 기준으로 재사용.
- ④ **금융 공백**: 카카오 로컬 BK9 범주를 지역 대표점마다 거리순으로(지점 3곳 확보까지 최대 3페이지) 받아 합집합을
  `mart.bank_place` 에 둔다. 최근접 지점은 반드시 합집합에 들어가므로 KNN 이 정확(20km 안). ATM·우체국은 제외.
- ⑤ **배치 제안**: 폐국 = 지역별 직선 상위 8곳을 미리 구한 탐욕법(k ≤ 7 이면 재탐색 불필요), 신설 = 읍면동 대표점 후보의
  p-median 탐욕 근사(15km 안 효과). 둘 다 가중치(65세 이상/인구) × 거리 변화(명·km). 결정 근거가 아닌 검토용으로 표시.
