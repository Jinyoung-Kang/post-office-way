# ADR-015 생활 거점(약국·병의원)과 영업일 달력(특일 정보)

- 상태: 채택 (2026-09-25)

## 맥락
보유·검증된 공공 API(V-World·부동산원·DART·도로공사·에어코리아·철도·기상청 단기/중기·TAGO 열차/지하철·서울 버스·
e약은요·아파트 실거래가·주식시세·약국·병의원·우편번호·특일) 중 무엇을 더할지. 기준은 **우체국 접근성이라는 질문을
더 깊게 만드는가**, 전국을 빠짐없이 덮는가, 호출 비용이 감당되는가.

## 결정
1. **국립중앙의료원 약국·병의원 FullData** — 좌표 + 요일별·**공휴일** 진료시간. 약국 25,442 · 의원급 이상 42,514곳, 호출 약 110회.
   - 집계구(평균 500명)마다 2순위 금융 우체국·은행 지점·약국·의원·공휴일 진료처까지 거리 → `oa_nearest` 열로 저장.
   - **우체국이 마지막 생활 거점**(2km 안 우체국만, 은행·약국·의원 없음)인 인구, 의료 공백, 공휴일 의료 공백 지표.
   - **우체국별 대체 불가능성**(`facility_hub`): 닫히면 2km 안 금융 창구/모든 생활 거점을 잃는 인구 → 생활 거점 화면·시설 카드·
     What-if(`lifeHubLostPpltn`)·배치 제안(제안 목록에 경고)까지 연결. 단순 '가까운 약국 찾기'가 아니라 폐국 의사결정의 제약 조건.
2. **한국천문연구원 특일 정보(공휴일)** — 연 1회 조회로 대체·임시공휴일까지. 주말과 함께 **창구 휴무일** 판정:
   방문 여건 날짜에 휴무 표시와 '연휴 모드'(365코너 없는 읍면동, 공휴일 진료 공백), 머리글 알림, 시설 카드의 '지금 영업 중/휴무' 상태.

## 제외한 것과 이유
| API | 제외 이유 |
|---|---|
| V-World | 경계·주소는 SGIS·카카오로 이미 확보 |
| 부동산원·아파트 실거래가 | 법정동 코드 체계라 행정동(SGIS)과 매핑 부담 대비 접근성 질문과 거리가 멂(수요 신호로는 인구 통계가 더 직접적) |
| Open DART·주식시세·e약은요 | 우체국 접근성과 무관 |
| 한국도로공사·철도·TAGO 열차/지하철 | 고속도로·철도는 농산어촌 고령자의 창구 방문 경로와 거리가 멂 |
| 서울 버스 노선 | 서울 한정 — 전국 비교가 핵심인 서비스에 부분 적용은 왜곡 |
| 기상청 중기예보 | 권역 단위 오전/오후 요약이라 단기예보(격자·시간) 대비 판정 정밀도가 낮음 |
| 우정사업본부 도로명주소(우편번호) | 좌표 검증은 카카오 주소 검색으로 이미 수행 |

## 한계
- 직선거리·집계구 대표점 기준. 공휴일 진료는 **등록된 진료시간** 기준(당번 약국과 다를 수 있음). 치과·한의원·요양병원 제외.
